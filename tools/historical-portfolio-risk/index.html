Historical Portfolio Risk

Measure a fixed-weight periodically rebalanced portfolio from aligned return histories, including volatility, drawdown and historical loss quantiles.

Runs fully in your browser Synthetic example included Learning tool · not investment advice
What it does

Replays a fixed-weight, periodically rebalanced portfolio through actual return histories to measure volatility, the worst peak-to-trough fall, and bad-period loss levels.

What you enter

Aligned periodic returns (for example monthly) for each asset, and the fixed portfolio weights. All series must cover the same periods. The prefilled example is synthetic.

How to read the results

Annualized volatility, maximum drawdown, and historical VaR and expected shortfall: the loss level only the worst 5% of periods exceeded, and the average of those worst periods.

Keep in mind

History doesn't repeat on schedule, and short histories understate rare events. These are historical measures, not predictions.
